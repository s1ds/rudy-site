# Rudy Site

This repository is the master source for the Rudy website, books, and games.

## Layout

- `Home/` — homepage, books page, and website media
- `Games/Shapes-mat/` — deployable Shapes Mat plus its Vite source in `source/`
- `Games/Shapes-bingo/` — deployable Shapes Bingo plus its Vite source in `source/`
- `Games/Shape-reveal/source/` — Shape Reveal Vite source
- `Games/rudy-tangram-lab/` — existing Tangram Lab files (no separate repository was imported)
- `Hostinger Upload/` — current hosting bundle
- `source-docs/` — source documents used by the site

The `main` branch is the combined site. The `books` branch is retained for book-related work and currently starts from the same consolidated snapshot.

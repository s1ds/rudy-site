# Rudy's Shape Mat

A touch-first web game based on Rudy's 12-piece EVA shape mat. Match each loose shape to its jigsaw-edged base, then use the completed tiles to build a 4×3 mat, house, castle, or bridge.

## Run locally

```sh
pnpm install
pnpm dev
```

## Build

```sh
pnpm test
pnpm build
```

The static `dist/` output can be hosted as a full page or embedded in an iframe. For fullscreen support inside an iframe, include `allow="fullscreen"` on the iframe element.
